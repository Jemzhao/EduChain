# API 契约目录

- 状态：Complete

本目录概括 OpenAPI 中已经实现的端点族、调用方、权限和关键语义。机器可读字段、operationId、响应与错误以 `packages/api-contract/openapi/openapi.yaml` 为唯一事实来源。

## 1. 认证与账户

| 端点族                                                           | 能力                                     | 权限      | 关键语义                     |
| ---------------------------------------------------------------- | ---------------------------------------- | --------- | ---------------------------- |
| `/auth/registrations`                                            | 注册                                     | 匿名      | 限流、唯一性、防枚举         |
| `/auth/sessions*`                                                | 登录、匿名会话探测、退出、列出和撤销会话 | 匿名/本人 | 匿名探测不以错误表示未登录   |
| `/auth/token-refreshes`                                          | 刷新                                     | 刷新会话  | 轮换与重用检测               |
| `/auth/password-reset-requests`、`/auth/password-resets`         | 申请和完成重置                           | 匿名      | 一次性令牌、统一提示         |
| `/auth/password-changes`                                         | 修改密码                                 | 本人      | 验证原密码并撤销其他会话     |
| `/users/me`                                                      | 本人资料                                 | 本人      | 读取与更新分离 DTO           |
| `/users/me/resources`、`/users/me/history`、`/users/me/activity` | 本人内容和活动                           | 本人      | 按本人范围过滤               |
| `/users/me/search-history*`                                      | 搜索历史读取与清理                       | 本人      | 单项删除、全部清空、数量限制 |
| `/users/{handle}`                                                | 公开资料                                 | 公开      | 只返回公开字段               |

## 2. 资源、文件与分类

| 端点族                                            | 能力                         | 权限             | 关键语义                   |
| ------------------------------------------------- | ---------------------------- | ---------------- | -------------------------- |
| `/resources`、`/resources/{resourceKey}`          | 公开列表、创建草稿、资源详情 | 公开/用户        | 公开可见性与本人视图分离   |
| `/resources/{id}/draft`、`/publications`          | 草稿保存与发布               | 作者             | 乐观并发、幂等发布         |
| `/resources/{id}/versions`、`/draft-restorations` | 版本列表与恢复               | 作者             | 不可变版本、恢复生成新草稿 |
| `/resources/{id}/withdrawals`、`/restorations`    | 主动下架与恢复               | 作者             | 原因、生命周期和审计       |
| `/resources/{id}/views`、`/statistics`            | 浏览记录与资源统计           | 公开/作者        | 去重计数、作者范围         |
| `/categories`、`/tags`                            | 分类树、标签和建议           | 公开             | 只返回启用项，输入数量受限 |
| `/uploads*`                                       | 创建、传输和完成上传         | 用户/所有者      | 用途、配额、摘要和幂等     |
| `/files/{fileId}`、`/files/{fileId}/content`      | 文件状态与受控内容           | 所有者或授权主体 | 不暴露存储键，响应权限受控 |

## 6. 平台治理

管理端点统一在 `/admin` 下；普通用户端点不能通过隐藏参数启用管理能力。

| 端点族                                                                                  | 能力             | 权限 | 关键语义                                               |
| --------------------------------------------------------------------------------------- | ---------------- | ---- | ------------------------------------------------------ |
| `/admin/overview`、`/statistics*`                                                       | 总览、统计和导出 | 管理 | 聚合读取、受控导出                                     |
| `/admin/users*`、`/admin/user-deletion-batches`、`/admin/user-exports`                  | 用户完整治理     | 管理 | 创建、编辑、角色保护、安全密码设置、批量停用和导出审计 |
| `/admin/resources*`、`/admin/resource-review-batches`、`/admin/resource-exports`        | 内容审核治理     | 管理 | 单项/批量通过拒绝、回收区、状态通知和导出审计          |
| `/admin/comments*`、`/admin/reports*`                                                   | 评论和举报治理   | 管理 | 软隐藏、恢复、处理结论                                 |
| `/admin/taxonomy*`、`/admin/categories*`、`/admin/tags*`                                | 分类标签维护     | 管理 | 层级、合并、停用、安全删除、批量治理和引用检查         |
| `/admin/settings*`                                                                      | 平台设置         | 管理 | 类型化值、键白名单、审计                               |
| `/admin/maintenance-jobs`                                                               | 平台维护         | 管理 | 操作白名单、原因、任务结果                             |
| `/admin/audit-events`、`/admin/system-health`                                           | 审计和能力健康   | 管理 | 只读、脱敏、可观测                                     |
| `/admin/operational-metrics`、`/admin/operational-events`、`/admin/operational-alerts*` | 运维观测和告警   | 管理 | 聚合指标、去敏摘要、版本化关闭与审计；不暴露原始日志   |

## 9. 契约完成规则

每个端点均需要具备：

- 需求编号和调用入口。
- 请求和响应 Schema。
- 认证、角色和对象级权限。
- 成功状态码与稳定错误码。
- 幂等、并发、分页、筛选与排序规则。
- 数据敏感级别与审计边界。
- Mock 正常和失败语义。
- 日志、指标或审计要求。

## 10. 兼容性

- 同一主版本内只做向后兼容扩展。
- 新增必填字段、改变枚举语义、删除字段或改变状态码属于破坏性变化。
- 枚举增加值时，前端必须具有未知值降级策略。
- 实验字段不得进入正式契约，除非有明确隔离和移除条件。
