# ADR-0004：区块链能力使用独立存证网关

- 状态：Accepted

## 背景

论文技术路线使用 Python、FastAPI 和长安链 SDK。核心业务使用 Java。若 Java Server 直接依赖链 SDK，会让密钥、错误模型和网络细节侵入业务模块，也不利于本地模拟。

## 决策

建立独立 FastAPI Evidence Gateway，通过内部 API 向 Java Server 提供提交、查询、核验和证书能力。真实长安链与本地模拟器实现相同适配器接口，运行模式启动时固定。

## 选择原因

- 保持论文技术路线。
- 隔离 SDK、节点证书、私钥和网络错误。
- Java 业务状态与具体链实现解耦。
- 本地演示可以完整运行且来源清楚。

## 后果

- Server 与 Gateway 之间需要内部认证、超时、追踪和幂等。
- 出现跨服务结果未知状态，需要可靠任务和查询补偿。
- 需要分别维护真实链和模拟器适配器的一致语义。

## 未选方案

- Java 直接接长安链：业务边界和密钥边界较弱。
- 只提供模拟器：无法完成真实链技术验证。
- 失败自动切换模拟器：会混淆证明来源和真实性。
