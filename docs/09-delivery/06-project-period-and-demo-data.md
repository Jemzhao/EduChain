# 项目周期与演示数据时间口径

- 状态：Accepted

## 1. 项目周期

EduChain 的集中设计与优化周期统一定义为：

- 开始：2026 年 6 月 25 日。
- 正式结束：2026 年 7 月 31 日。

变更说明、演示资源、社区互动、通知、工单、治理、审计、存证证明和维护任务等用户可见项目数据，均使用这一时间区间。该口径用于保证答辩叙事、界面展示、Mock 接口和文档表达互相一致。

## 2. 阶段解释

| 日期       | 阶段         | 形成的主要成果                                                               |
| ---------- | ------------ | ---------------------------------------------------------------------------- |
| 2026-06-25 | 设计基线     | 产品范围、三应用边界、模块化 MVC、OpenAPI、错误模型、设计与国际化原则        |
| 2026-06-30 | 工程基础     | Web、Java Server、存证网关、数据库、Mock、共享类型和通用组件                 |
| 2026-07-08 | 核心内容闭环 | 账户资料、四类资源、上传、发布、公开阅读、版本与恢复状态                     |
| 2026-07-16 | 发现与社区   | 分类检索、可解释排序、互动、通知、动态、社区、贡献排行和成就                 |
| 2026-07-23 | 存证与治理   | 模拟器、长安链适配边界、任务、核验、证书、账本、管理后台和审计               |
| 2026-07-31 | 正式收敛     | 安全、性能、可访问性、国际化、可观测性、演示数据、信息页面和交付文档统一检查 |

这些阶段用于解释成果形成顺序，不代表依赖发布时间，也不用于改写真实运行环境产生的事实。

## 3. Mock 场景时钟

前端 Mock 使用确定性场景时钟：

1. 初始业务数据均落在 2026 年 6 月 25 日至 7 月 31 日之间。
2. 页面内新建、更新、回复、核验和治理动作使用区间末段的递增时间，刷新后不会因系统日期变化而出现八月或更晚的演示记录。
3. 资源发布时间覆盖完整区间，社区发布流、发现结果和存证时间由同一资源事实派生。
4. 存证提交和确认时间必须晚于对应资源发布时间，并保持在项目区间内。
5. 现有浏览器会话通过 Mock 数据版本升级获得本轮完整种子数据，不继续读取旧的稀疏样本。

## 4. 不应改写的时间

以下时间保留其真实语义，不强行限定为项目周期：

- Java Server、数据库和真实存证网关运行时生成的日志、指标、会话与审计时间。
- 软件依赖的版本号、发布年份和许可证信息。
- 用户在真实后端模式下实际创建业务数据的时间。
- 文件系统元数据、构建工具输出和开发机器系统时间。

原因是这些时间属于运行事实或第三方软件事实，伪造会破坏可观测性、安全审计和复现能力。项目周期只约束项目说明与确定性演示场景。

## 5. 展示与核对规则

- 关于页说明整体周期与系统定位。
- 变更说明按阶段展示具体日期和成果。
- Mock 社区、发现、详情、通知、工单、管理和账本使用同一时间边界。
- 中英文日期通过 `Intl.DateTimeFormat` 按当前语言格式化，不在组件中手写展示格式。
- 新增演示数据必须复用场景时钟，不得直接读取当前系统日期。
- 任何超出区间的用户可见 Mock 时间均属于数据缺陷，需要在交付前修正。
