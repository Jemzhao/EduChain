## 1. 核验边界

本记录覆盖工程基础、核心业务、存证、治理与扩展能力。本轮核验包含仓库自动化测试、契约与生成物检查、三应用静态分析、生产构建、完整容器启动、真实后端 API 闭环、浏览器端登录与管理页面验收，以及本地模拟存证、核验和证书验证。

“本地模拟存证”只证明三应用、数据库、任务状态机与证书链路能够完整协作，不等同于真实长安链网络上链。真实长安链仍需要部署方提供节点、组织证书、私钥、官方 SDK 与已部署合约后单独验收。

## 3. 架构核对

- 根目录不保留旧工程源码或旧仓库历史，并提供许可证、贡献指南、安全策略、社区模板与 CI 工作流。
- Web 业务组件只依赖共享数据访问层，Mock 和 Remote 使用相同 URL、方法、请求与响应类型。
- OpenAPI、Mock handler 与 Java Controller 均为 147 个 HTTP 操作；路径和方法保持同一契约边界。
- 用户可见内容由 Intlayer 管理；中文与英文使用同一内容键和区域格式化规则。
- Java Controller 处理 HTTP 边界，Service 持有事务、状态和权限，Repository 服务所属模块；跨模块治理通过目标模块服务协作。
- 管理端已按总览、用户、内容、分类、存证与可观测性拆分 Controller 和 Service，不存在统一万能管理服务；共享响应组装集中在专用 Mapper。
- 知识、存证、用户、社交与认证之间的双向实现依赖已改为平台端口和稳定快照；`shared` 不依赖任何业务模块。
- Entity 不作为 API 响应，DTO 不 import Entity；API 可见状态与类型位于各模块 `domain` 包。错误使用稳定错误码、请求标识、安全参数与可重试标志。
- Web 管理入口、管理分区、Mock handler、Mock state、资源编辑器状态与视图均按用例拆分，路由页保持薄层。
- Web 容器构建上下文通过根级 `.dockerignore` 隔离，不传入本机依赖、构建产物、Java Server、存证网关或归档内容。
- 公开列表、搜索、推荐与统计使用批量读取或聚合结果，避免资源卡逐项访问证明状态。
- 存证完成态不会在可靠任务恢复时回退，人工重试保留原始幂等键和审计原因。
- 资源本人下架、管理下架、恢复和公开可见性使用一致生命周期，并保留公开证明记录。

## 8. 部署验收前置项

- 真实长安链环境需要部署方提供官方 SDK、网络、合约、组织证书和最小权限密钥，再完成连通与证书核对。
- 正式域名、TLS、秘密管理、备份存储、监控采集端和告警责任人属于部署环境输入，不能写死在项目中。
- 当前核验已包含整套本地容器启动，但不包含生产域名、正式 TLS、远程秘密管理、备份介质与外部监控平台。
- 当前自动化测试覆盖关键纯规则、网关 API、模拟器、长安链适配契约、证书生成与运行安全校验；浏览器组件级自动化、性能容量、依赖漏洞、攻击面扫描和真实长安链网络仍属于部署前独立门禁。
