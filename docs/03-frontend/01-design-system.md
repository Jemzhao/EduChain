# 视觉与设计系统规范

- 状态：Accepted

## 1. 设计方向

EduChain 的视觉关键词是：可信、克制、清晰、温和、专业。参考 Apple 和 Google 成熟产品的共同特征：留白充分、信息层级明确、控件一致、动效有目的、内容优先。

不追求品牌官网式炫技，也不模仿金融行情大屏。区块链能力通过准确的信息与状态表达建立可信感，而不是通过未来感装饰。

## 2. 明确禁止

- 大面积霓虹色、荧光蓝紫和高饱和渐变。
- 玻璃拟态叠层、背景模糊堆叠和透明卡片墙。
- 无信息价值的 3D 地球、粒子网络、链条动画。
- 每个区块都使用卡片、阴影和圆角。
- 同一页面出现多套圆角、多套阴影或多套图标风格。
- 仅为“高级感”加入的滚动视差和持续漂浮动画。
- 使用红绿作为唯一状态区分。

## 3. 色彩系统

### 3.1 基础角色

| 角色           | 用途                 | 方向               |
| -------------- | -------------------- | ------------------ |
| Canvas         | 页面背景             | 温和中性白或近黑   |
| Surface        | 导航、表单、局部容器 | 与 Canvas 轻微区分 |
| Text Primary   | 标题与主要正文       | 高对比中性色       |
| Text Secondary | 辅助说明             | 仍满足可读性       |
| Border         | 分隔与控件边界       | 低对比但可识别     |
| Accent         | 主操作、链接、焦点   | 单一稳重蓝色       |
| Success        | 完成与匹配           | 受控绿色           |
| Warning        | 等待与风险           | 受控琥珀色         |
| Danger         | 破坏性操作与失败     | 受控红色           |

### 3.2 使用规则

- 品牌强调色在一个视图中的面积应受控。
- 状态颜色必须同时配合文字或图标。
- 暗色模式不是简单反色，需要独立检查层级和对比度。
- 图表色板使用语义顺序，不使用随机彩虹色。

### 3.3 主题偏好

- 全局支持浅色、深色和跟随系统三种偏好，入口固定在站点导航中。
- 偏好仅保存在当前浏览器，不写入账户资料，也不依赖业务后端或 API 模式。
- 首次绘制前应用已保存偏好，避免页面先显示错误主题再跳变。
- 浅色与深色共用语义令牌，组件不得直接判断主题或定义私有主题颜色。
- 控件必须提供可读名称、明确当前状态、键盘操作和系统偏好降级。

## 4. 排版

- 中文优先使用系统无衬线字体栈；英文使用相同视觉家族，减少额外字体下载。
- 正文默认 16px，行高约 1.65；长文阅读宽度控制在约 68 至 76 个英文字符的等效范围。
- 标题层级依靠字号、字重和间距，不依靠全大写或装饰线。
- 数值、哈希和交易标识使用可读的等宽字体，并提供复制和截断后的完整访问方式。
- 最多使用四个主要字号层级与三个常用字重。

## 5. 空间与布局

- 使用 4px 基础单位，常用间距为 8、12、16、24、32、48、64。
- 页面最大内容宽度按场景分为阅读、表单、列表和宽表格四类。
- 桌面端外层留白充足；移动端优先保留可点击面积和正文宽度。
- 同一分组内间距小于分组之间间距。
- 表单标签、帮助文字、输入框和错误文字形成稳定节奏。

## 6. 圆角、边框和阴影

- 小控件使用 8px 左右圆角；容器使用 12px 左右圆角；药丸形只用于标签和明确的分段控件。
- 默认通过背景和 1px 边框建立层级。
- 阴影只用于浮层、菜单、对话框和需要脱离文档流的对象。
- 不在静态卡片网格中使用重阴影。

## 7. 动效

- 常规反馈约 120–180ms，布局过渡约 180–240ms。
- 使用标准缓动，不使用弹簧抖动作为默认反馈。
- 动效必须帮助理解状态变化、空间关系或操作结果。
- 系统设置减少动态效果时，移除非必要动画并缩短必要动画。

## 8. 核心组件清单

基础控件：Button、IconButton、Link、Input、Textarea、Select、Checkbox、Radio、Switch、Combobox、DateInput、FilePicker。

反馈控件：InlineAlert、Toast、Progress、Skeleton、Spinner、EmptyState、ErrorSummary、StatusBadge。

导航控件：Header、Sidebar、Breadcrumb、Tabs、Pagination、CommandSearch。

数据控件：ResourceCard、ResourceListItem、DataTable、DescriptionList、Metric、Timeline。

浮层控件：Dialog、Drawer、Popover、DropdownMenu、Tooltip。

业务模式：EvidenceSummary、VerificationResult、UploadQueue、PublishChecklist、CommentThread、NotificationItem、AdminActionPanel。

## 9. 组件状态

每个交互组件至少定义：默认、悬停、按下、焦点可见、禁用、加载、错误和成功状态。组件文档必须说明键盘行为、ARIA 语义、内容长度边界和移动端表现。

## 10. 页面审美验收

- 5 秒内能识别页面目的和主要操作。
- 首屏只有一个明确的主操作层级。
- 重要信息不依赖装饰背景。
- 去掉颜色后，层级仍然成立。
- 文案变为英文后，布局仍可用。
- 200% 缩放下核心任务仍可完成。
- 加载、空、错误和权限状态与正常状态同等精心。
