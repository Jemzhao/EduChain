# API、数据访问与事务规范

- 状态：Accepted

## 1. API 基础规范

- 基础路径：`/api/v1`。
- 资源名使用复数名词和短横线。
- HTTP 方法表达语义：GET 读取、POST 创建或命令、PUT 完整替换仅在适合时使用、PATCH 局部更新、DELETE 删除或撤销。
- 业务命令使用清晰子资源，例如发布、重试、标记已读，不用含糊的 `action` 参数。
- 时间使用 ISO 8601 UTC 字符串。
- 标识符作为字符串传输，避免前端数值精度问题。

## 2. 成功响应

- 单对象返回明确资源 DTO。
- 创建成功使用 201，并在适用时提供资源位置。
- 无响应体的成功操作使用 204。
- 异步受理使用 202，并返回任务标识和当前状态。
- 不为所有成功响应强制增加无价值的 `code: 200` 包装。

## 3. 错误响应

统一包含：

- `type`：稳定错误文档标识。
- `title`：通用错误标题键或安全文本。
- `status`：HTTP 状态码。
- `code`：稳定业务错误代码。
- `detail`：可安全展示的补充说明，可选。
- `instance`：请求路径或问题实例。
- `requestId`：关联标识。
- `fieldErrors`：字段级错误列表，可选。
- `retryable`：是否建议重试。
- `parameters`：供前端内容字典插值的安全参数，可选。

后端错误文本不作为前端最终文案的唯一来源。

## 4. 状态码约定

| 状态码 | 语义                   |
| ------ | ---------------------- |
| 400    | 结构或通用请求错误     |
| 401    | 未认证或会话失效       |
| 403    | 已认证但无能力访问     |
| 404    | 对调用者不可见或不存在 |
| 409    | 唯一性、状态或版本冲突 |
| 413    | 请求或上传超过限制     |
| 415    | 不支持的媒体类型       |
| 422    | 字段语义校验失败       |
| 429    | 请求过多               |
| 500    | 未预期内部错误         |
| 502    | 依赖服务返回无效结果   |
| 503    | 服务暂不可用           |
| 504    | 依赖服务超时           |

## 5. 分页与排序

- 普通列表使用游标分页优先；管理后台可在必要时使用页码分页。
- 默认页大小 20，最大 100。
- 游标是不可解释的稳定字符串，包含排序边界但不暴露敏感数据。
- 排序字段使用白名单，不把数据库列名直接暴露给调用方。
- 响应包含项目、下一游标和是否有下一页；总数只在有明确产品价值时计算。

## 6. 筛选

- 多值筛选规则在接口目录中逐项定义。
- 空字符串不等同于未提供。
- 日期范围包含性和时区语义必须明确。
- 搜索词执行长度、字符和速率限制。

## 7. 幂等

必须提供幂等键的操作：

- 发布资源。
- 创建上传会话。
- 提交存证。
- 手工重试外部副作用。
- 批量通知操作。

服务端保存幂等键、调用主体、请求摘要、结果引用和过期时间。相同键但不同请求摘要返回冲突。

## 8. 乐观并发

- 可编辑聚合包含版本号。
- 更新请求携带预期版本。
- 版本不一致返回 409 和当前资源最小必要信息。
- 前端明确提示重新加载或人工合并，不静默覆盖。

## 9. Repository 查询规范

- 所有列表查询有明确排序。
- 所有外部输入通过参数绑定。
- 禁止无界 `findAll` 进入线上用例。
- 避免 N+1：使用投影、实体图或明确 join 查询，并通过日志和性能检查确认。
- 管理查询与公开查询使用不同投影，减少敏感字段暴露。
- 批量更新记录影响行数，并校验是否符合预期。

## 10. 数据结构版本管理

- 每个脚本只追加，不修改已在共享环境执行的脚本。
- 脚本命名包含递增版本和短说明。
- 表、列、索引、约束和数据修正规则分开说明风险。
- 大表变更在执行前评估锁时间和磁盘空间。
- 应用启动对结构版本执行校验，正式环境不允许应用账户任意修改结构。

## 11. 事务清单

| 用例     | 单事务内容               | 事务外内容             |
| -------- | ------------------------ | ---------------------- |
| 注册     | 用户、凭据、默认设置     | 欢迎通知               |
| 发布     | 版本、可见状态、可靠任务 | 索引、存证、证书       |
| 点赞     | 唯一关系、计数策略       | 分析聚合               |
| 评论     | 评论、通知意图           | 外部通知               |
| 下架     | 状态、原因、审计意图     | 缓存和索引更新         |
| 存证确认 | 证明记录、任务状态       | 证书文件生成或后续通知 |

## 12. 数据访问安全

- 应用数据库账户采用最小权限。
- 生产不使用 root 账户。
- 备份和只读分析使用独立账户。
- 敏感字段在日志、调试端点和序列化中默认隐藏。
- 删除和保留策略在数据文档中逐实体定义。
