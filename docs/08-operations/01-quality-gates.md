# 实现阶段质量门禁

- 状态：Accepted

本轮已执行仓库现有的 Java 与 Evidence Gateway 自动化测试、Web 和网关静态检查、OpenAPI 校验、生产构建、容器集成验证与真实后端浏览器复核。组件、压力、攻击面扫描与真实长安链网络验收仍按本文件作为后续部署门禁，不用局部通过替代完整质量体系。

## 1. 合并前静态门禁

### Web

- 格式检查。
- ESLint 零阻断错误。
- TypeScript 严格类型检查。
- Intlayer 内容键、缺失语言和未使用内容检查。
- OpenAPI 生成产物与规范一致。
- 禁止硬编码用户可见文案。
- 禁止跨功能深层导入和循环依赖。

### Java Server

- 格式与编译检查。
- 静态分析与空值约束。
- 模块依赖规则检查。
- API DTO 不得引用 Entity。
- 数据结构脚本校验和检查。
- OpenAPI 规范生成一致。

### Evidence Gateway

- 格式、静态类型和依赖检查。
- API Schema 与内部模型边界检查。
- 禁止真实链密钥和配置样例进入制品。

### 结构边界

根目录执行 `pnpm structure:check`，用于阻断以下回退：

- 缺少许可证、贡献指南、安全策略、社区模板或 CI 工作流。
- CI 引用的第三方 Action 未固定到完整提交摘要。
- 出现归档目录或重复契约生成物。
- Web 容器构建上下文缺少依赖、构建产物与无关应用的隔离规则。
- Web 路由、业务组件、管理分区或 Mock 模块超过职责预算。
- 真实前端模块直接依赖 Mock 实现。
- Java Controller 访问 Repository、DTO 依赖 Entity、Shared 依赖业务模块。
- 知识与存证模块重新注入对方的具体 Service。
- Gateway application 层反向依赖 API 或 adapter。

结构检查与编译、类型检查、测试互补；通过编译不代表模块边界合格。

## 2. 测试层次

| 层次       | 目标                      | 重点                           |
| ---------- | ------------------------- | ------------------------------ |
| 单元       | 纯规则和状态转换          | 排序、状态机、规范化、权限判断 |
| 组件       | UI 交互和可访问性         | 表单、对话框、状态组件         |
| Repository | SQL、映射和约束           | 唯一性、分页、锁、投影         |
| Service    | 用例与事务                | 授权、幂等、任务记录           |
| API        | HTTP 契约                 | 状态码、错误、认证、校验       |
| 契约       | Web、Server、Gateway 一致 | Schema、枚举、兼容性           |
| 端到端     | 核心闭环                  | 注册、发布、搜索、核验、治理   |
| 安全       | 常见攻击与配置            | 越权、上传、XSS、限流          |
| 性能       | 预算与容量                | 搜索、列表、发布、任务积压     |

## 3. 覆盖目标

不以单一覆盖率百分比替代质量判断。以下内容必须直接覆盖：

- 身份令牌轮换与撤销。
- 对象级授权和管理保护规则。
- 资源发布幂等与并发冲突。
- 文件状态和发布绑定限制。
- 摘要规范化、Merkle Tree 和核验结果。
- 存证结果未知、重试和任务租约。
- Mock 与真实契约的字段和错误一致性。
- 公开页面核心可访问性。

## 4. 视觉质量门禁

- 关键页面在手机、平板、普通桌面和宽屏检查。
- 中文和英文分别检查。
- 亮色和暗色分别检查。
- 正常、加载、空、错误、权限和长内容状态分别检查。
- 键盘、焦点、200% 缩放和减少动态效果设置检查。
- 截图差异必须由设计变更说明支持。

## 5. 安全门禁

- 依赖漏洞检查无未处置的严重或高风险问题。
- 密钥扫描无真实凭据。
- 管理端点全部具有授权验证。
- 上传白名单与文件签名校验开启。
- 安全响应头和 Cookie 属性符合规范。
- 日志样本无敏感信息。

## 6. 发布阻断条件

- 任一核心流程无法完成。
- OpenAPI 与实现不一致。
- Mock 模式掩盖真实后端缺失能力。
- 数据结构版本校验失败。
- 关键安全或越权问题未解决。
- 正式环境可启用模拟器或 Mock。
- 已确认存证被错误显示为失败或模拟结果被显示为真实链。
- 核心页面不满足基本键盘操作和对比度要求。

## 7. 证据保存

每个里程碑保存：

- 需求到验证的追踪表。
- 构建与静态检查结果。
- 核心流程验证记录。
- 视觉状态清单。
- 已知限制和风险接受记录。
- 技术版本与环境摘要。
