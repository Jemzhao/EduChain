# 环境、配置与可观测性

- 状态：Accepted

实现映射：Web 在非本地环境拒绝 Mock；Server 与 Gateway 在生产等价环境拒绝模拟存证或不安全 Cookie；Java 暴露 Actuator 健康与 Prometheus 指标，Gateway 提供带服务身份保护的指标端点；三应用统一传播请求标识并记录不含查询内容的访问元数据。

## 1. 环境模型

| 环境             | 目的                 | 数据           | 外部证明               | Mock     |
| ---------------- | -------------------- | -------------- | ---------------------- | -------- |
| Local Mock       | 纯前端开发与设计评审 | 可复现场景数据 | 不适用                 | 必须启用 |
| Local Integrated | 本地全栈             | 本地测试数据   | 本地模拟器             | 关闭     |
| Integration      | 团队联调与契约验证   | 隔离数据       | 模拟器或隔离链         | 关闭     |
| Demonstration    | 答辩与受控演示       | 固定演示数据   | 明确选择模拟器或真实链 | 关闭     |
| Production-like  | 非公开生产等价验证   | 脱敏或生成数据 | 隔离真实链             | 关闭     |

首版不假设存在公开生产环境，但环境模型必须能支持未来正式部署。

## 2. 配置原则

- 配置与制品分离。
- 环境变量只承载部署差异，不承载复杂业务规则。
- 密钥、密码、证书和令牌由秘密管理提供。
- 每个应用启动时验证必需配置，缺失时快速失败。
- 配置键有统一前缀、类型、默认值、敏感级别和责任人。
- 正式环境禁止危险默认值，包括模拟器、宽松 CORS、调试日志和通用密码。

## 3. 配置分组

- 应用：名称、环境、公共基址、端口。
- 数据库：地址、库名、连接池和超时。
- Redis：地址、认证、前缀和超时。
- 文件：提供者、桶、限制、签名有效期。
- 身份：令牌签名、有效期、Cookie 和允许来源。
- 存证：网关地址、服务身份、证明模式和超时。
- 可观测性：日志级别、指标端点、追踪采样。
- 前端：API 基址、API 模式、站点 URL、默认语言。

## 4. 日志规范

统一字段：

- 时间、级别、服务、环境、版本。
- 请求标识、追踪标识、跨度标识。
- 路由模板、方法、状态码、耗时。
- 用户匿名标识，只有授权场景记录稳定内部标识。
- 业务对象类型和标识。
- 错误代码、异常分类和是否可重试。

禁止记录：密码、访问与刷新令牌、完整 Cookie、私钥、数据库密码、完整文件内容、完整证书私钥材料和未脱敏个人资料。

## 5. 指标

### 5.1 通用服务指标

- 请求量、成功率、错误率和延迟分布。
- 运行实例、线程、内存、CPU 和连接池。
- 数据库查询延迟、连接池等待和慢查询数量。
- Redis 请求、命中率、错误和延迟。

### 5.2 业务指标

- 注册、登录成功和登录失败。
- 草稿创建、发布成功、发布失败。
- 搜索量、无结果率、点击率和常用筛选。
- 上传拒绝率与原因。
- 存证任务各状态数量、确认时间和终止数量。
- 证书生成成功率。
- 通知积压与已读率。

业务指标用于系统质量，不以收集不必要个人行为为代价。

管理工作台提供的是受控投影：JVM 堆使用率、工作卷使用率、单处理器负载和可重试存证任务数；事件由不可编辑审计记录投影为分类与安全摘要；告警按组件和摘要码去重并使用乐观并发关闭。原始日志、进程参数、异常堆栈、邮箱、正文和令牌不通过管理接口返回。

## 6. 追踪

- 浏览器到 Web、Server、Gateway 的请求传播 W3C Trace Context。
- 资源发布、存证提交和证书生成跨异步任务时使用链接或延续上下文。
- 追踪属性不包含正文、文件名、邮箱或完整哈希。
- 高延迟和错误请求提高采样概率，普通成功请求采用合理采样。

## 7. 健康检查

- `liveness`：进程是否能继续运行，不检查所有外部依赖。
- `readiness`：是否能安全接收请求，检查关键本地资源。
- `dependencies`：单独报告 MySQL、Redis、对象存储、Gateway 和 ChainMaker 状态。
- 依赖状态端点按权限限制，不泄漏连接信息。

## 8. 告警候选

- API 5xx 比例持续超过阈值。
- 登录失败或限流突然异常。
- 数据库连接池持续耗尽。
- 搜索无结果率突增。
- 文件扫描或上传队列积压。
- 存证任务在某状态超过正常时长。
- 模拟器在非允许环境启动。
- 证书生成持续失败。

每个告警必须有意义、责任人和处理说明，避免只对瞬时波动报警。

## 9. 备份与恢复目标

- MySQL：定期完整备份与增量日志，恢复目标在部署文档冻结时明确。
- 对象存储：版本或备份策略覆盖资源和证书。
- Redis：按可重建定位决定持久化，不把 Redis 备份当业务恢复唯一手段。
- 模拟器数据：演示环境可备份，明确不等同真实链备份。
- 恢复演练必须验证资源、版本、文件引用和证明记录之间的一致性。
