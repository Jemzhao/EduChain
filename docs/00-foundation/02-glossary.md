# 术语表

- 状态：Accepted

| 术语         | 定义                                                                           | 不应混用                 |
| ------------ | ------------------------------------------------------------------------------ | ------------------------ |
| 知识资源     | 用户发布的教育内容聚合体，包含元数据、正文和附件                               | 不简称为“文件”           |
| 资源版本     | 一次可独立识别的已发布内容快照                                                 | 不等同于编辑中的草稿     |
| 草稿         | 尚未公开、允许持续编辑的资源状态                                               | 不参与公开核验           |
| 发布         | 生成公开版本并进入后续索引、存证流程                                           | 不表示存证已完成         |
| 摘要         | 通过确定性规则计算的 SHA-256 值                                                | 不称为加密内容           |
| 存证         | 将资源版本的证明数据提交到指定证明后端                                         | 不等同于上传原文到链上   |
| 存证任务     | 管理提交、确认、失败和重试的异步任务                                           | 不等同于链上交易本身     |
| 核验         | 重新计算内容摘要并与已登记证明比对                                             | 不承诺法律结论           |
| 证书         | 对存证事实的可读展示文件                                                       | 不是所有权转让合同       |
| 真实链模式   | 存证网关连接真实长安链节点                                                     | 必须与模拟模式显式区分   |
| 本地模拟模式 | 使用本地确定性存储模拟证明流程                                                 | 不得展示为真实链上结果   |
| 智能检索     | 基于文本相关度、元数据和质量信号的可解释综合检索                               | 不等同于大模型问答       |
| Mock 模式    | 前端通过网络拦截器返回契约一致的模拟响应                                       | 不允许组件内写假数据分支 |
| 真实后端模式 | 前端访问部署的 Java API 和存证能力                                             | 不意味着必须连接真实链   |
| 内容字典     | Intlayer 管理的类型安全用户文案集合                                            | 不等同于业务数据         |
| 模块化 MVC   | 按业务模块组织、模块内保持 Controller-Service-Repository-Entity 分层的单体架构 | 不称为微服务或 DDD       |
| DTO          | HTTP 边界上的输入输出对象                                                      | 不直接暴露 Entity        |
| 幂等键       | 识别同一业务请求、阻止重复副作用的稳定键                                       | 不使用随机重试值替代     |
| 审计日志     | 记录谁在何时对什么对象执行了什么管理动作                                       | 不等同于普通应用日志     |
| 设计令牌     | 视觉基础值的统一命名与来源                                                     | 不在组件内重复写魔法值   |

## 命名约定

- 中文产品名统一为“EduChain 教育知识共享平台”。
- 英文品牌名统一为“EduChain”。
- API 字段、数据库字段和代码标识使用英文。
- 用户界面中的“存证”英文使用 `Evidence`；“核验”使用 `Verification`。
- “资源”英文使用 `Knowledge Resource`，避免在同一上下文中混用 `Post`、`Article`、`Item`。
