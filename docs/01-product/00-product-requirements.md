# 产品需求规格

- 状态：Accepted

## 1. 核心用户

### 1.1 学习者

目标是快速发现可信、结构清楚的教育资源，保存内容并参与讨论。主要痛点是资源质量难判断、检索结果噪声高、收藏和学习记录分散。

### 1.2 教育内容创作者

目标是低摩擦发布内容、形成可公开展示的原创证明、观察内容传播和互动。主要痛点是发布流程复杂、版权信息缺失、存证状态难理解。

### 1.3 平台管理员

目标是在可审计前提下处理用户、内容、评论、分类和失败任务。主要痛点是信息分散、权限过大、操作缺少上下文。

## 2. 关键用户旅程

### J-01 发现并保存资源

进入首页 → 使用搜索或分类 → 查看结果与筛选 → 打开资源详情 → 判断作者与原创证明 → 收藏或加入收藏夹。

### J-02 发布并完成存证

登录 → 新建草稿 → 编辑内容与元数据 → 上传附件 → 预览 → 发布 → 查看索引与存证进度 → 下载证书 → 打开公开核验页。

### J-03 验证外部文件

打开核验页 → 输入证明标识或上传待验证文件 → 本地或服务端计算摘要 → 比对已登记记录 → 查看匹配、未匹配或无法确认结果。

### J-04 参与社区互动

阅读资源 → 点赞、评论或关注作者 → 接收回复和更新通知 → 管理通知偏好。

### J-05 管理员处理风险内容

进入管理后台 → 查看待处理事项 → 检查资源、作者、举报和审计上下文 → 执行受控动作 → 填写原因 → 记录结果。

## 3. 功能需求

### 3.1 身份与账户

- `FR-AUTH-001` 用户可以通过唯一邮箱或用户名注册。
- `FR-AUTH-002` 用户可以登录、退出并刷新会话。
- `FR-AUTH-003` 用户可以申请密码重置，重置凭据一次有效且短时有效。
- `FR-AUTH-004` 用户可以查看和撤销其他会话。
- `FR-AUTH-005` 受限或停用用户收到明确但不过度暴露的提示。
- `FR-PROFILE-001` 用户可以维护头像、显示名、简介和教育背景。
- `FR-PROFILE-002` 公开主页展示已发布资源、关注关系和公开统计。

### 3.2 资源创作

- `FR-KNOWLEDGE-001` 创作者可以创建和保存草稿。
- `FR-KNOWLEDGE-002` 草稿包含标题、摘要、正文、分类、标签、封面、附件和版权声明。
- `FR-KNOWLEDGE-003` 系统提供明确的保存状态，避免用户误认为内容已保存。
- `FR-KNOWLEDGE-004` 发布前执行字段、附件、内容安全和权限校验。
- `FR-KNOWLEDGE-005` 每次发布生成不可变的公开版本标识。
- `FR-KNOWLEDGE-006` 创作者可以下架资源，但已生成的存证记录保持可追溯。
- `FR-KNOWLEDGE-007` 删除遵循软删除和审计规则，不能破坏引用完整性。

### 3.3 浏览与检索

- `FR-SEARCH-001` 用户可以按关键词搜索标题、摘要、正文索引、作者、分类和标签。
- `FR-SEARCH-002` 用户可以组合筛选条件，并看到可撤销的筛选状态。
- `FR-SEARCH-003` 结果支持相关度、最新、热度和质量排序。
- `FR-SEARCH-004` 结果明确展示命中信息、资源状态、作者和存证标识。
- `FR-SEARCH-005` 无结果时提供拼写、分类、标签或清除筛选建议。
- `FR-SEARCH-006` 系统记录脱敏后的检索行为，用于质量分析和建议词。
- `FR-SEARCH-007` 排序使用可解释信号，不因单一互动指标被轻易操纵。

### 3.4 互动与关系

- `FR-SOCIAL-001` 登录用户可以点赞或取消点赞。
- `FR-SOCIAL-002` 登录用户可以收藏资源，并管理收藏夹。
- `FR-SOCIAL-003` 登录用户可以发表评论和受控回复。
- `FR-SOCIAL-004` 评论删除后保持引用结构稳定并显示合理占位。
- `FR-SOCIAL-005` 用户可以关注或取消关注其他正常用户。
- `FR-NOTIFY-001` 系统为评论回复、关注、内容状态和存证结果生成站内通知。
- `FR-NOTIFY-002` 用户可以单条或批量标记已读并配置通知偏好。

### 3.5 存证与核验

- `FR-EVIDENCE-001` 发布版本生成规范化内容摘要和文件摘要。
- `FR-EVIDENCE-002` 同一资源版本的重复提交不得产生不可控的重复证明。
- `FR-EVIDENCE-003` 存证任务显示等待、处理中、已确认、失败和终止状态。
- `FR-EVIDENCE-004` 确认后保存证明后端、交易标识、区块信息和时间信息。
- `FR-EVIDENCE-005` 证书显示资源、作者、摘要、证明来源和核验入口。
- `FR-EVIDENCE-006` 核验结果区分匹配、不匹配、未找到和暂时无法确认。
- `FR-EVIDENCE-007` 模拟结果必须带有不可去除的环境标识。

### 3.6 管理治理

- `FR-ADMIN-001` 管理员可以按条件查找用户和查看必要上下文。
- `FR-ADMIN-002` 用户状态修改需要原因、权限校验和审计记录。
- `FR-ADMIN-003` 管理员可以处理资源、评论和举报。
- `FR-ADMIN-004` 分类和标签修改具备冲突检查与引用统计。
- `FR-ADMIN-005` 管理员可以查看失败的存证任务和受控重试入口。
- `FR-ADMIN-006` 管理台展示业务健康数据，不把普通日志直接暴露给管理员。

## 4. 业务规则摘要

- 草稿只有作者和授权管理员可见。
- 发布版本一旦进入存证流程，其摘要输入不可改变。
- 下架不等于删除证明；公开页可以显示资源已下架，但证明事实仍可核验。
- 点赞、收藏和关注关系在同一主体组合上唯一。
- 评论作者可以删除自己的评论；管理员可以因治理原因隐藏评论。
- 分类是受治理的单选主结构；标签是多选辅助结构。
- 管理动作必须附带原因，原因属于审计信息，不作为公开内容展示。

## 5. 非功能需求索引

- `NFR-SEC-*`：身份、授权、上传、内容与审计安全。
- `NFR-PERF-*`：页面、接口、搜索和异步任务性能。
- `NFR-A11Y-*`：键盘、语义、对比度、焦点和辅助技术。
- `NFR-OBS-*`：日志、指标、追踪、告警和健康检查。
- `NFR-MAINT-*`：模块边界、契约、文档和依赖治理。
- `NFR-I18N-*`：中文、英文、路由、格式化和内容完整性。
