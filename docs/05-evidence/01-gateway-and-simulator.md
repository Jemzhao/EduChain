# 存证网关与本地模拟器

- 状态：Accepted

## 1. 网关职责

网关向 Java Server 提供稳定内部 API，并通过适配器连接真实长安链或本地模拟器。它负责技术证明，不负责最终业务授权。

## 3. 内部 API 能力

- 提交证明。
- 查询提交和确认状态。
- 按证明标识或交易标识读取证明。
- 计算或验证摘要。
- 生成或重新生成证书。
- 查询网关能力、模式和依赖健康状态。

所有写请求要求服务身份、请求标识、幂等键和载荷版本。

## 4. 适配器接口语义

真实链和模拟器必须提供一致能力：

- `submit`：提交或返回已有结果。
- `get_status`：返回规范化状态。
- `get_proof`：返回规范化证明信息。
- `verify`：对摘要和记录执行比对。
- `health`：报告自身状态与能力。

适配器原始错误统一映射为超时、临时不可用、拒绝、配置错误、无效响应和结果未知。

## 5. 真实长安链适配器

- SDK 与节点配置集中在 `adapters/chainmaker`。
- 证书、私钥和 TLS 配置通过秘密管理注入。
- 启动时验证链 ID、组织 ID、合约和必要能力。
- 交易提交和查询分别设置超时。
- 原始 SDK 响应先校验，再映射为内部模型。
- 日志只记录必要标识，不记录私钥、证书内容或完整敏感配置。

## 6. 本地模拟器

模拟器的目的：无长安链时提供可复现的接口行为、状态转换和核验演示。

### 6.1 必须做到

- 使用真实 SHA-256 和相同规范化规则。
- 使用确定性交易标识、区块序列和时间控制。
- 支持等待、确认、临时失败、结果未知和终止场景。
- 持久化到独立本地存储，使服务重启后结果可继续查询。
- 每个响应和证书写明 `SIMULATOR` 来源。

### 6.2 明确禁止

- 生产环境自动回退到模拟器。
- 使用与真实链完全相同且无法区分的网络名称。
- 在公开证书中隐藏模拟器标识。
- 为了演示成功而跳过摘要和幂等检查。

## 7. 模式配置

- `chainmaker`：只使用真实链，依赖不可用时失败并暴露健康状态。
- `simulator`：只使用本地模拟器，适用于开发和演示。

不提供失败自动切换模式。模式在启动时固定，运行时不能通过普通 API 改变。

## 8. 证书生成

- 证书数据模型与 PDF 模板分离。
- 使用嵌入字体保证中文跨平台显示。
- 生成文件包含模板版本和内容摘要。
- 二维码目标使用配置化公开基址和稳定证明标识。
- 相同证明与模板版本生成语义一致的证书。
- 文件写入对象存储后返回对象引用，不向 Java Server 返回本地绝对路径。

## 9. 安全

- 网关不面向公网。
- 内部身份与普通用户令牌分离。
- 请求体大小和并发受限。
- 核验临时文件进入隔离目录并自动清理。
- 依赖健康端点不泄漏节点地址、证书路径和组织私密信息。

## 10. 可观测性

指标至少包括：

- 提交量、确认量、失败量和结果未知量。
- 提交、确认和证书生成延迟。
- 各适配器错误分类。
- 任务积压与重试次数。
- ChainMaker 节点健康和 SDK 调用耗时。
- 模拟模式启动标志。
