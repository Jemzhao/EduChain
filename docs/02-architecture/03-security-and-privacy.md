# 安全与隐私架构

- 状态：Accepted

## 1. 信任边界

- 浏览器完全不可信。
- Web 服务端可以保护服务端配置，但不持有长安链私钥。
- Server 是业务授权中心，但不能直接读取 Gateway 私钥。
- Gateway 运行在限制网络区域，仅接受 Server 的内部认证调用。
- MySQL、Redis、对象存储和长安链使用独立最小权限凭据。

## 2. 身份认证

- 密码使用 Argon2id 或经评审的自适应算法。
- 访问令牌有效期短；刷新令牌仅以安全、HttpOnly、SameSite Cookie 传递。
- 刷新令牌服务端保存哈希、设备信息、过期时间和撤销状态。
- 令牌轮换后旧令牌立即失效；检测重用时撤销相关会话族。
- 登录、重置密码和高风险管理动作有独立限流策略。

## 3. 授权

- 路由级角色校验只做第一层保护。
- Service 层执行对象级授权和业务状态校验。
- Repository 查询必须有清晰的可见性条件，不把所有数据加载后再过滤。
- 管理员操作使用显式管理接口，避免普通接口出现隐藏超级权限分支。

## 4. Web 安全

- CSP 默认拒绝未知脚本、框架、对象和嵌入来源。
- 设置 HSTS、`X-Content-Type-Options`、合理的 Referrer Policy 和 Permissions Policy。
- 对 Cookie 认证写操作执行 CSRF 保护。
- 外部链接使用安全的 `rel` 属性；用户输入 URL 经过协议和域名规则检查。
- 服务端渲染内容只使用已清洗 HTML，不接受任意脚本或事件属性。

## 5. 上传安全

- 允许类型使用明确白名单。
- 扩展名、声明 MIME 和文件签名必须一致。
- 文件名只作显示，存储键由服务端生成。
- 上传对象先进入隔离区域，通过检查后才能公开访问。
- 设定单文件、单次、单用户和单位时间配额。
- PDF、图片和压缩包按照各自风险配置检查；禁止递归解压不受控内容。

## 6. API 安全

- 所有请求模型限制长度、数量、格式和枚举范围。
- 分页有最大页大小，批量接口有最大对象数。
- 错误响应统一，不暴露账号是否存在等可枚举信息。
- 重要写操作使用幂等键和乐观并发版本。
- 对搜索、评论、关注和核验入口实施滥用检测与限流。

## 7. 内部服务安全

- Server 与 Gateway 使用双向 TLS 或短时服务身份令牌。
- Gateway 只开放必要内部端点，不提供公共管理面。
- 长安链证书、私钥和节点配置通过秘密管理注入，不进入镜像、日志或代码仓库。
- 本地模拟器使用独立环境配置，生产环境禁止启用模拟回退。

## 8. 隐私与数据最小化

- 只收集完成账户、创作、互动和安全目的所需数据。
- 搜索行为分析使用用户标识脱敏与明确保留期限。
- 核验临时文件在完成或超时后自动删除。
- 日志不记录密码、令牌、完整 Cookie、私钥、文件内容和不必要的个人资料。
- 用户公开资料与内部账户数据使用不同 DTO。

## 9. 审计事件

至少记录：

- 管理角色授予与撤销。
- 用户状态修改。
- 内容和评论治理动作。
- 分类标签结构修改。
- 失败证明任务的手工操作。
- 安全配置和密钥引用变化。

审计记录包含操作者、动作、目标、原因、时间、请求标识和结果，不允许通过普通业务接口修改。

## 10. 威胁检查清单

- 身份伪造：凭据填充、令牌盗用、会话固定。
- 权限提升：水平越权、角色伪造、管理员接口误用。
- 内容攻击：XSS、恶意文件、公式或嵌入内容注入。
- 数据攻击：SQL 注入、批量枚举、敏感字段泄漏。
- 业务滥用：刷赞、刷收藏、垃圾评论、搜索抓取、证明任务耗尽。
- 外部依赖：链节点欺骗、TLS 配置错误、SDK 响应异常、结果未知。
- 可用性：缓存雪崩、上传耗尽、慢查询、任务积压。
